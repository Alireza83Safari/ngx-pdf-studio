# راهنمای کامل دیزاینر PDF Studio

این راهنما از صفر تا خروجی‌گرفتن PDF، کار با دیزاینر را قدم‌به‌قدم آموزش می‌دهد.
هیچ پیش‌نیازی لازم نیست؛ فقط مرورگر.

---

## ۱. مفاهیم پایه — دو دقیقه، ولی مهم

قبل از شروع، چهار مفهوم را بشناس؛ بقیهٔ راهنما روی همین‌ها سوار است:

| مفهوم                  | یعنی چی؟                                                                      |
| ---------------------- | ----------------------------------------------------------------------------- |
| **قالب (Template)**    | طرح سند تو: صفحه + الِمان‌ها + تنظیمات. یک فایل JSON قابل ذخیره و انتقال است. |
| **الِمان (Element)**   | هر چیزی که روی صفحه می‌گذاری: متن، فیلد داده، شکل، بارکد، چارت…               |
| **دادهٔ نمونه (Data)** | یک JSON آزمایشی که موقع طراحی به‌جای دادهٔ واقعی می‌نشیند.                    |
| **بایند (Binding)**    | وصل‌کردن یک الِمان به داده — مثلاً «این متن، اسم مشتری را نشان بده».          |

**نکتهٔ طلایی:** چیزی که روی بوم می‌بینی _دقیقاً_ همان PDF نهایی است (WYSIWYG واقعی) —
پس‌زمینهٔ بوم را خودِ موتور رندر می‌کند، نه یک شبیه‌سازی.

---

## ۲. اجرا و باز کردن

```bash
npm install
npm run designer:build     # فقط بار اول (یا بعد از آپدیت موتور)
```

بعد فایل `apps/playground/designer/designer.html` را در مرورگر باز کن.
در WSL:

```bash
explorer.exe "$(wslpath -w apps/playground/designer/designer.html)"
```

نه سروری لازم است، نه اینترنتی — همه‌چیز آفلاین کار می‌کند.

## ۳. آشنایی با محیط

```
┌───────────────────── نوار بالا ─────────────────────┐
│ P │ نام سند │ واگرد/ازنو │ پیش‌نمایش/مقادیر/⌘K │ قالب‌ها │ فایل │ 🌙 │ دانلود PDF │
├──┬──────────────────────────────────────┬───────────┤
│ر │                                      │ پنل راست  │
│ی │            بوم (کاغذ)               │ ┌────────┐ │
│ل │                                      │ │طراحی    │ │
│  │                                      │ │لایه‌ها  │ │
│ا │                                      │ │داده     │ │
│ب │                                      │ └────────┘ │
│زا│                                      │           │
│ر │                                      │           │
├──┴──────────────────────────────────────┴───────────┤
│ زوم │ ۱:۱ │ جا بده │ A4 · عمودی │ وضعیت انتخاب │ ذخیره ✓│
└──────────────────────── نوار وضعیت ──────────────────┘
```

| بخش                      | چه‌کار می‌کند                                                                                                                                             |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ریل ابزار** (کنار بوم) | ۱۲ ابزار: متن، فیلد داده، مستطیل، خط، بیضی، تصویر، بارکد، QR، چارت، **جدول**، **فیلد برچسب‌دار**، **شماره صفحه**. کلیک = افزودن؛ کشیدن روی بوم = همان‌جا. |
| **بوم**                  | کاغذ توست. نوارِ باندِ فعال روی کاغذ کشیده می‌شود و بقیهٔ صفحه هاشور می‌خورد؛ هرچه از مرزِ باند بیرون بزند قرمز علامت می‌خورد.                            |
| **تب طراحی**             | خواص الِمان انتخاب‌شده (قرارگیری، محتوا، ظاهر، جعبه و کادر، شرط‌ها) + تنظیمات صفحه.                                                                       |
| **تب لایه‌ها**           | فهرست همهٔ الِمان‌ها + سبک‌های نامدار + اجزای ذخیره‌شده.                                                                                                  |
| **تب داده**              | دادهٔ نمونهٔ JSON + چیپ‌های فیلد برای بایند سریع + فهرستِ هشدارهای زندهٔ موتور.                                                                           |
| **نوار وضعیت**           | زوم، اندازهٔ کاغذ، وضعیت انتخاب، شمارندهٔ هشدارها، نشانگر سرریزِ باند، نشانگر ذخیرهٔ خودکار.                                                              |

💡 روی هرچیزی که مطمئن نیستی، **ماوس را نگه دار** — تولتیپ توضیح می‌دهد.

## ۴. اولین طراحی — قدم‌به‌قدم (یک کارت تبریک ساده)

هدف: یک کارت با اسم شخص از روی داده + یک QR.

1. **قالب‌ها** را بزن → کارت اول «**سند خالی**» را انتخاب کن. بوم سفید با راهنمای وسطش می‌آید.
2. در تب **طراحی**، بخش «صفحه»: اندازه را **سفارشی…** بگذار و ابعاد `400 × 250` بده. جهت کاغذ: افقی.
3. از ریل، ابزار **متن (T)** را بگیر و بکش وسط‌بالای کارت رها کن.
4. **دابل‌کلیک** روی متن → بنویس «تبریک می‌گوییم!» → Enter.
5. در تب طراحی، بخش «ظاهر»: اندازهٔ فونت ۲۲، ضخیم ✓، رنگ دلخواه.
6. حالا اسم شخص از دیتا: برو تب **داده** — چیپ `customer.name` را بگیر و بکش زیر تیتر رها کن. یک فیلد بایندشده ساخته می‌شود که همین حالا «علی رضایی» (از دادهٔ نمونه) را نشان می‌دهد.
7. از ریل، **QR** را بکش گوشهٔ پایین. انتخابش کن، در «محتوا» مقدارش را بگذار: `'https://example.ir'` (رشته‌ها داخل کوتیشن).
8. یک **خط** تزئینی زیر تیتر بکش؛ با فلش‌های کیبورد میلی‌متری تنظیمش کن.
9. **دانلود PDF** را بزن — همین! کارت واقعی با فونت فارسی می‌گیری.
10. از منوی **فایل → ذخیرهٔ طرح (JSON)** طرحت را نگه دار.

همین ده قدم، ۹۰٪ کار با دیزاینر است. بقیهٔ راهنما عمق همین‌هاست.

## ۵. کار با داده و بایندها — قلب ماجرا

### دادهٔ نمونه

تب **داده → دادهٔ نمونه** یک JSON است. هر ساختاری بدهی، فیلدها به آن بایند می‌شوند:

```json
{
  "customer": { "name": "علی رضایی" },
  "invoice": { "number": "INV-1405-0042" },
  "items": [{ "name": "کالای اول", "qty": 2, "price": 1250000 }]
}
```

تا تایپ می‌کنی، بوم و چیپ‌های فیلد به‌روز می‌شوند.

### سه راه بایند کردن

1. **کشیدن چیپ روی بوم** → فیلد جدید بایندشده همان‌جا ساخته می‌شود. (ساده‌ترین راه)
2. **کشیدن چیپ روی یک الِمان موجود** → بایند همان الِمان عوض می‌شود.
3. **دستی**: الِمان را انتخاب کن → «محتوا → بایند» → عبارت را بنویس.

### زبان عبارت (Expression)

بایند فقط «مسیر» نیست — یک زبان امن و کوچک است:

| می‌خواهی…   | بنویس                               |
| ----------- | ----------------------------------- |
| مقدار ساده  | `customer.name`                     |
| عضو آرایه   | `items[0].name`                     |
| محاسبه      | `qty * price`                       |
| جمع یک ستون | `sum(items, qty * price)`           |
| متن ترکیبی  | `'آقای/خانم ' + customer.name`      |
| شرطی        | `total > 1000000 ? 'ویژه' : 'عادی'` |
| تعداد       | `len(items)`                        |

مرجع کامل توابع: [expression-language.md](expression-language.md).

### مقدار نمونه ↔ نام فیلد

دکمهٔ **🔢 مقادیر** در نوار بالا، بوم را بین «علی رضایی» و `{customer.name}` سوییچ می‌کند —
برای وقتی می‌خواهی ببینی چه چیزی به کجا بایند شده.

## ۶. ابزارها — نکته‌های هر کدام

| ابزار              | نکته‌های مهم                                                                                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **متن**            | دابل‌کلیک = ویرایش سریع. برای متن ثابت (عنوان‌ها، برچسب‌ها).                                                                                               |
| **فیلد داده**      | دابل‌کلیک = ویرایش بایند. خروجی‌اش از دیتا می‌آید.                                                                                                         |
| **مستطیل / بیضی**  | پُری، کادر (هر ضلع جدا، توپر/خط‌چین/نقطه‌چین)، گردیِ گوشه و شفافیت — همه در «جعبه و کادر».                                                                 |
| **خط**             | جداکننده‌های افقی؛ رنگ خط در ظاهر.                                                                                                                         |
| **تصویر**          | **فایل را روی بوم بینداز** یا دکمهٔ «انتخاب تصویر». PNG/JPEG در قالب جاسازی می‌شود و بدون اینترنت چاپ می‌شود. «برازش»: contain/cover/fill.                 |
| **جدول**           | به یک آرایه بایند می‌شود؛ ستون‌ها را با عنوان/منبع/عرض ویرایش کن. سرستون در هر صفحه تکرار می‌شود.                                                          |
| **فیلد برچسب‌دار** | برچسب + مقدار داخل یک کادر — همان چیزی که فرم‌ها و فاکتورها لازم دارند.                                                                                    |
| **شماره صفحه**     | شماره/تعداد کل/تاریخ. فقط داخل «سرصفحه» و «پاصفحه» مقدار می‌گیرد.                                                                                          |
| **بارکد**          | نوع: Code128 (متن/عدد)، Code39، EAN-13 (۱۲–۱۳ رقم). دابل‌کلیک = تغییر مقدار. متن خوانا زیر میله‌ها به‌صورت پیش‌فرض روشن است.                               |
| **QR**             | هر متنی، معمولاً URL. واقعاً اسکن می‌شود — با گوشی امتحان کن!                                                                                              |
| **چارت**           | به یک آرایه در دیتا بایند می‌شود: «دیتاست» = اسم آرایه (مثل `items`)، «دسته‌ها» = فیلد برچسب، «مقادیر» = فیلد/عبارت عددی. نوع: ستونی/میله‌ای/خطی/دایره‌ای… |

## ۶.۵ لوگو و فونتِ خودت

**لوگو:** فایل PNG یا JPEG را مستقیم **روی بوم بینداز** — یا الِمان تصویر را انتخاب کن و
«انتخاب تصویر…» را بزن. تصویر داخلِ خودِ قالب جاسازی می‌شود، پس فایلِ JSON همه‌چیز را با
خود می‌برد و PDF بدون اینترنت هم درست چاپ می‌شود.

> SVG پذیرفته نمی‌شود و دلیلش را هم می‌گوید: موتور نمی‌تواند SVG را در PDF جاسازی کند،
> پس در پیش‌نمایش دیده می‌شد و در چاپ غیب می‌شد.
> آدرسِ اینترنتی هم فقط در پیش‌نمایش دیده می‌شود، در PDF جاسازی **نمی‌شود**.

**فونت:** در تب لایه‌ها → «فونت‌ها» یک TTF/OTF بار کن (مثلاً ایران‌سنس یا وزیرمتن). بعد
از آن، «فونت» در بخش ظاهر آن خانواده را نشان می‌دهد و هم روی بوم و هم در PDF استفاده
می‌شود. فونت هم داخل قالب جاسازی می‌شود.

> بومِ طراحی متن را با **همان فونتی** اندازه می‌گیرد که PDF جاسازی می‌کند، پس خط دقیقاً
> همان‌جا می‌شکند که روی کاغذ می‌شکند.

## ۶.۶ هشدارهای زنده

نوار وضعیت یک شمارندهٔ هشدار دارد که **حین طراحی** روشن می‌شود، نه موقع خروجی:
بایندِ اشتباه، دیتاستِ اعلام‌نشده، بارکدِ نامعتبر، سرریزِ باند و…

کلیک روی شمارنده تو را به فهرست در تب داده می‌برد؛ هر ردیف دکمهٔ **«برو»** دارد که
الِمانِ مقصر را انتخاب می‌کند — حتی اگر در باندِ دیگری باشد.

> هشدارها روی **کلِ سند** حساب می‌شوند، نه فقط باندی که باز است. پس پاصفحهٔ خرابِ
> نادیده نمی‌ماند.

## ۷. تکنیک‌های چیدمان حرفه‌ای

- **جابه‌جایی**: بگیر و بکش. الِمان‌ها خودکار به شبکهٔ ۵pt و **لبهٔ الِمان‌های دیگر** می‌چسبند (خط قرمز راهنما = هم‌تراز شدی). `Alt` را نگه‌دار تا snap خاموش شود.
- **تغییر اندازه**: **هشت دستگیره** (چهار گوشه + چهار لبه). گوشه هر دو بُعد را می‌کشد،
  لبه فقط یکی. `Shift` نسبتِ اصلی را نگه می‌دارد.
- **چرخش**: دستگیرهٔ گِردِ بالای انتخاب. `Shift` روی پله‌های ۱۵ درجه می‌نشیند.
- **جابه‌جایی دقیق**: فلش‌های کیبورد = ۱pt، با `Shift` = ۱۰pt.
- **چندانتخابی**: `Shift`+کلیک، یا روی جای خالی بوم **کادر بکش** (marquee).
- **هم‌ترازی**: با ۲+ الِمان انتخاب‌شده، تب طراحی دکمه‌های تراز (چپ/وسط/راست/بالا/میان/پایین) و با ۳+ «توزیع» را نشان می‌دهد.
- **ترتیب (جلو/عقب)**: از نوار شناور بالای انتخاب یا بخش «قرارگیری».
- **لایه‌ها**: وقتی چیزها روی هم‌اند، از تب لایه‌ها انتخاب کن — دقیق و بی‌دردسر.
- **کپی**: `Ctrl+D` یا دکمهٔ کپی در نوار شناور.
- **زوم**: `Ctrl`+چرخ موس، یا نوار وضعیت (۱:۱ = اندازهٔ واقعی چاپ، «جا بده» = کل صفحه در نما).

## ۸. قالب‌ها — شروع سریع‌تر

دکمهٔ **قالب‌ها**: **۲۲ طرح آماده** در شش دسته — مالی و فروش، اداری و منابع انسانی،
گزارش و تحلیل، بازاریابی و رویداد، برچسب و کارت — همه با پیش‌نمایش زندهٔ واقعی.
«سند خالی» برای شروع از صفر؛ فاکتور، پیش‌فاکتور، رسید، گزارش فروش (با چارت)، سربرگ،
برچسب محصول، لیست بسته‌بندی، کارت ویزیت، منوی رستوران، گزارش کارکرد، گواهی‌نامه و…
برای شروعِ از وسط راه. با جست‌وجو و تعویضِ تمِ رنگی.

کلیک روی هر کارت، **قالب + دادهٔ نمونه‌اش** را با هم لود می‌کند — بعد به سلیقهٔ خودت تغییرش بده.

## ۹. تنظیمات صفحه

تب طراحی → بخش «صفحه»:

- **اندازه**: A4 / A5 / A3 / Letter / Legal، یا **سفارشی…** (عرض×ارتفاع به واحدِ جاری).
- **واحد**: پونت / **میلی‌متر** / **سانتی‌متر**. همهٔ اعدادِ چیدمان (ابعاد کاغذ، حاشیه،
  x/y/w/h، ارتفاع باند) با همین واحد نشان داده و خوانده می‌شوند — پس برای برچسبِ
  ۱۰×۶ سانتی، `cm` را انتخاب کن و `10 × 6` بنویس. دیگر لازم نیست چیزی را دستی ضرب کنی.
  > ذخیره همیشه به پونت است؛ واحد فقط نمایش را عوض می‌کند، نه خروجی را.
  > اندازهٔ فونت، ضخامت کادر و شعاعِ گوشه همیشه پونت می‌مانند — مثل هر ابزار طراحیِ دیگر.
- **جهت کاغذ**: عمودی/افقی.
- **حاشیه**: چهار ضلع، با گزینهٔ «هر چهار طرف یکی». ناحیهٔ محتوا از این خط شروع می‌شود
  و روی بوم با خط‌چین دیده می‌شود.
- **نوشتار**: RTL برای فارسی (پیش‌فرض)، LTR برای اسناد لاتین.
- **ارقام**: فارسی (۱۲۳) یا لاتین (123) — روی خروجیِ چاپی اثر می‌گذارد.
- **تقویم**: جلالی (شمسی) یا میلادی — تاریخ‌ها با همین تقویم نوشته می‌شوند.

## ۱۰. ذخیره و خروجی

| کار               | چطور                                                                                                  |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| **PDF نهایی**     | دکمهٔ آبی «دانلود PDF» — با فونت فارسی وزیرمتنِ embed شده، متن قابل انتخاب و جست‌وجو.                 |
| **ذخیرهٔ طرح**    | فایل → ذخیرهٔ طرح (JSON). این فایل، قالب کامل توست.                                                   |
| **بازکردن طرح**   | فایل → بارگذاری طرح (JSON).                                                                           |
| **ذخیرهٔ خودکار** | همیشه روشن است (نشانگر «ذخیره شد ✓» در نوار بالا). مرورگر را ببندی و برگردی، از همان‌جا ادامه می‌دهی. |
| **سند نو**        | فایل → سند نو (پیش‌نویس قبلی پاک می‌شود — اول JSON بگیر اگر لازمش داری).                              |

فایل JSON طرح را می‌توان مستقیم به موتور داد و در سرور Node یا برنامهٔ Angular با دادهٔ
واقعی رندر کرد — طراحی یک‌بار، تولید بی‌نهایت. ([getting-started.md](getting-started.md))
